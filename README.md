# Live360 Viewer Server — это автономное Android-приложение, превращающее ТВ-приставку (или любое Android-устройство) в полноценный сервер для USB-камер панорамной съемки (Huawei CV60 и аналогичные). Приложение захватывает видео с камеры через USB (SCSI/UVC), декодирует его и раздает в локальную сеть по протоколу **WebRTC**, а также предоставляет встроенный **веб-сервер** для управления и настройки.

## 🌟 Основные возможности

* **Полная автономность (Kiosk Mode):** Приложение можно назначить лаунчером по умолчанию. После перезагрузки устройства трансляция запускается автоматически без участия человека.
* **Авто-подтверждение USB:** Встроенная служба специальных возможностей (Accessibility Service) автоматически нажимает «ОК» в системном диалоге разрешения доступа к USB, что позволяет устройству работать без участия оператора.
* **Механизм повторных попыток:** Если камера не успела инициализироваться после загрузки ОС, приложение сделает до 3 повторных попыток с интервалом в 10 секунд.
* **WebRTC Трансляция:** Задержка видео минимальна. Поддерживается два режима просмотра в браузере:
    * `webrtc_pano.html` — интерактивная 3D-панорама (с использованием библиотеки Pannellum).
    * `webrtc_2d.html` — плоское (развернутое) изображение.
* **Веб-панель управления:** Удобный интерфейс для управления стримом, смены разрешений, снятия скриншотов и просмотра логов в реальном времени (через SSE).
* **Смена разрешения на лету:** Возможность переключать разрешение видео (от 640×320 до 1920×960) прямо из веб-интерфейса или приложения без перезапуска сервера.
* **Снимки (Snapshots):** Возможность делать снимки (JPEG) напрямую с камеры через API и скачивать их, либо делать скриншот текущего WebRTC-кадра в браузере.

## 🏗 Архитектура

1. **USB Камера** (`LiveViewSession`) выдает сырой H.264 (Annex-B).
2. **Декодер** (`H264Decoder`) декодирует поток в Surface.
3. **WebRTC** (`SurfaceTextureCapturer` + `WebRtcServer`) захватывает кадры с Surface и отправляет их через WebSocket-сигналинг (порт `9090`) в браузер.
4. **Веб-сервер** (`WebServer`, порт `8080`) раздает статику из `assets/` (HTML, JS, CSS), а также предоставляет REST API и SSE-поток для управления.

## 🚀 Первоначальная настройка (Выполняется ОДИН раз)

Для того чтобы приставка работала автономно, необходимо правильно настроить её при первом запуске.

### Шаг 1: Установка и разрешения
1. Установите APK на ваше устройство (например, H96 Max).
2. Запустите приложение. Предоставьте все запрашиваемые разрешения (Камера, Микрофон, Память).
3. Подключите USB-камеру. Система спросит разрешение на доступ к устройству — нажмите **«ОК»**.

### Шаг 2: Включение Авто-подтверждения USB
Чтобы приставка перезагружалась и сама подключалась к камере, нужно включить службу специальных возможностей:
1. В приложении нажмите кнопку **«⚠️ ВКЛЮЧИТЕ АВТО-ПОДТВЕРЖДЕНИЕ USB»** (или перейдите в *Настройки Android -> Специальные возможности*).
2. Найдите в списке **Live360 Server** и включите переключатель.
3. Вернитесь в приложение. Кнопка должна стать зеленой: **«✅ АВТО-ПОДТВЕРЖДЕНИЕ USB ВКЛЮЧЕНО»**.

### Шаг 3: Назначение лаунчером (Автозапуск)
1. В приложении нажмите **«🏠 СДЕЛАТЬ ЛАУНЧЕРОМ (HOME)»**.
2. Выберите **Live360 Server** в качестве приложения по умолчанию для действия «Дом» (Home).
3. Теперь при перезагрузке приставка будет загружаться сразу в это приложение и автоматически запускать трансляцию.

## 🖥 Использование веб-интерфейса

Узнать IP-адрес устройства можно на главном экране приложения (в нижней части, зеленым шрифтом).
Обратите внимание: приложение автоматически определяет IP как для Wi-Fi, так и для Ethernet-подключения.

* **Главная панель управления:** `http://<IP-адрес>:8080/`
* **Панорама (3D):** `http://<IP-адрес>:8080/webrtc_pano.html`
* **2D (плоское видео):** `http://<IP-адрес>:8080/webrtc_2d.html`

### REST API (JSON)
Вы можете интегрировать сервер в свои системы, отправляя POST-запросы на `http://<IP-адрес>:8080/api/command`:

```json
// Пример: Запустить стрим
{"cmd": "start_stream"}

// Пример: Сменить разрешение на 1920x960 (0x0B)
{"cmd": "set_video_res", "payload": {"code": 11}}

// Пример: Сделать снимок (вернет Base64 в ответе)
{"cmd": "take_photo"}
```

* **Список команд:** `start_stream`, `stop_stream`, `take_photo`, `set_video_res`, `set_photo_res`, `set_web_port`, `ping`, `get_status`.
* **SSE (Server-Sent Events):** Подключитесь к `http://<IP-адрес>:8080/api/events` для получения статуса приложения в реальном времени.

## 🛠 Сборка проекта

* Android Studio (Electric Eel или новее)
* JDK 17
* Android SDK 34

1. Склонируйте репозиторий.

## 📂 Структура проекта

* `MainActivity.java` — связующее звено (UI, запуск серверов, обработка команд API, логика повторных попыток).
* `UsbPermissionService.java` — служба Accessibility для авто-нажатия кнопки «ОК» в системном диалоге USB.
* `WebServer.java` — легковесный HTTP/SSE сервер.
* `WebRtcServer.java` — менеджер WebRTC подключений (поддерживает множество клиентов).
* `SignalingServer.java` — WebSocket сервер для обмена SDP/ICE кандидатами.
* `SurfaceTextureCapturer.java` — кастомный «капчер» для WebRTC, получающий кадры из декодера.
* `H264Decoder.java` — обертка над `MediaCodec` для декодирования H.264 в Surface.
* `LiveViewSession.java` — низкоуровневая работа с SCSI-командами USB-камеры.
* `assets/` — веб-интерфейс (HTML, JS) и библиотеки Pannellum.

## ⚠️ Известные проблемы и решения

1. **Ошибка `ERR_CONNECTION_TIMED_OUT` при заходе с ПК:**
    * Убедитесь, что ПК и приставка находятся в одной подсети.
    * Отключите изоляцию клиентов (AP Isolation) на роутере.
    * Временно отключите брандмауэр Windows для проверки.
2. **Видео в браузере черное или зависает:**
    * Нажмите на кнопку «Включить звук» (браузеры блокируют автовоспроизведение со звуком без клика пользователя).
    * Убедитесь, что порт `9090` (WebSocket) не блокируется сетью.
3. **Камера не запускается после перезагрузки:**
    * Проверьте, что кнопка «АВТО-ПОДТВЕРЖДЕНИЕ USB» горит зеленым цветом.
    * В логах (Logcat, тег `MainActivity`) будут видны сообщения о попытках переподключения (`Повторная попытка 1/3` и т.д.).
